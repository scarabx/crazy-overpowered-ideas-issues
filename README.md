# COPI — Bug reports and suggestions

This is the issue tracker for **COPI (Crazy Overpowered Ideas)**, a Minecraft 1.20.1 Fabric mod.

- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/copi-crazy-overpowered-ideas)
- [Modrinth](https://modrinth.com/mod/crazy-overpowered-ideas-copi)

**The mod's source is private, so there is no code here** — this repository exists only so that
anyone can report a problem without joining anything.

## Reporting a bug

[Open an issue.](https://github.com/scarabx/crazy-overpowered-ideas-issues/issues/new) Please
include:

1. **The COPI version** — it is on the mod's page in-game and in the file name, e.g. `0.2.0+1.20.1`
2. **Minecraft and Fabric Loader versions**
3. **Other mods installed**, or at least whether you are in a modpack
4. **What you did and what happened**, in enough detail that someone else could do the same
5. **A crash report or log** if the game crashed — `.minecraft/crash-reports/` or `logs/latest.log`

Screenshots help, especially for anything about crafting on the ground or the recipe browser.

## Before you report

- **Crafting happens on the ground, not in a crafting table.** Drop the materials, hold the right
  tool and right-click. The crafting table doing nothing for vanilla items is deliberate.
- **GeckoLib is required.** The mod will not load without it.
- **Voice control is unfinished** and off by default. It needs Python set up by hand, and not
  working out of the box is expected rather than a bug.

## Suggestions

Welcome, in the same place. Say what the idea is and what it would be for; "what problem does this
solve" is more useful than a list of features.
